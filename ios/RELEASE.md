**Shtab.ipa** — приложение для iPhone без подписи. Ставится через Sideloadly или AltStore под твоим Apple ID.
**Shtab-Xcode.zip** — проект для Xcode: открой `ios/Shtab.xcodeproj`, выбери свою команду в Signing и нажми ▶ с подключённым iPhone.

С бесплатным Apple ID подпись действует 7 дней, потом приложение надо переустановить (данные сохраняются).
Внутри открывается https://stefannious.github.io/shtab/, поэтому обновления приходят сами, без переустановки.
