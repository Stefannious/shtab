# Штаб

Личное приложение для дисциплины: задачи, привычки, таблетки и витамины, питание, зал, прогресс и ассистент NOVA.

**Открыть:** https://stefannious.github.io/shtab/

## Поставить на iPhone
1. Открой ссылку выше в **Safari**.
2. «Поделиться» → «На экран „Домой“» → «Добавить».
3. Дальше открывай Штаб с этой иконки: на весь экран, работает и без интернета.

На Mac: Safari → «Файл» → «Добавить в Dock» (или Chrome → «Установить приложение»).

## Синхронизация телефона и ноутбука
Данные хранятся в твоём **приватном** репозитории `shtab-data`. В этом (публичном) репозитории их нет.

1. github.com → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Token name: `shtab`, Expiration — самый долгий.
3. Repository access → **Only select repositories** → `shtab-data`.
4. Permissions → Repository permissions → **Contents: Read and write**.
5. Generate token, скопируй (`github_pat_…`).
6. В Штабе: Настройки → Синхронизация → вставь токен → «Подключить». Так же на втором устройстве.

## Напоминания (пуш-уведомления)
Их рассылает GitHub Actions из этого репозитория каждые 10 минут: утро, время таблеток, вечер.

1. Этот репозиторий → **Settings → Secrets and variables → Actions → New repository secret**: Name `DATA_TOKEN`, Secret — тот же токен.
2. В Штабе на телефоне (открытом с экрана «Домой»): Настройки → Напоминания → «Включить уведомления».

Время утреннего и вечернего напоминания меняется там же. GitHub иногда запускает расписание с опозданием на 5–15 минут.

## NOVA
Нужен ключ Anthropic API (console.anthropic.com → API Keys): Настройки → NOVA. Ключ хранится только на устройстве. Из России NOVA работает с включённым VPN.

## Что где лежит
- `docs/` — само приложение. Сайт публикуется из ветки `gh-pages` (копия `docs/`): после изменений `docs/` обнови и её.
- `push/` — рассылка напоминаний, без внешних зависимостей.
- `.github/workflows/` — расписание напоминаний и «не засыпать» (GitHub выключает расписания в публичных репозиториях после 60 дней без коммитов).
- `src/` — исходники: `python3 build.py` собирает `pwa/` (→ `docs/`) и версию для Claude.
